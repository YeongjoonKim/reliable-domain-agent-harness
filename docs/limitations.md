# Scope & Limitations

실제 typed executor의 상담 통합, claim-level provenance, 완전한 replay는 PARTIAL입니다. MCP는 prototype이고 Scientific / Multi-Agent / Agent RL은 후속 범위입니다. [실제 구현 대응](actual-engineering.md)을 참고하세요.
